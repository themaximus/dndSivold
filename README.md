# ⚔️ D&D Sivold — Веб-платформа с ИИ-Мастером (DeepSeek / Gemini)

Полнофункциональный веб-сервис для многопользовательских настольных ролевых игр (D&D 5e) с глубокими механиками RPG, серверным античитом и ИИ в роли Мастера Подземелий (Dungeon Master).

---

## 🌟 Ключевые возможности

1. **ИИ-Мастер Подземелий (AI Dungeon Master)**:
   - Литературное повествование на русском языке в духе классического темного фэнтези.
   - Сведение действий всех игроков раунда в единую динамичную сцену.
   - Нейросетевая озвучка Edge Neural TTS с естественными интонациями и авто-очисткой от технического мусора.
   - Долгосрочный **Журнал событий (Lore Journal)**: память о прошлых обещаниях NPC, событиях и квентах без забивания контекста.

2. **Сложность ситуации (Target DC) и Обязательные броски d20**:
   - Мастер перед каждым раундом задает сложность (СЛ / Target DC: 10–20) и тактическое обоснование.
   - Игроки обязаны бросить `d20` перед завершением хода для оценки успеха.
   - Мгновенная оценка броска в UI: `УСПЕХ`, `ПРОВАЛ`, `КРИТИЧЕСКИЙ УСПЕХ`, `КРИТИЧЕСКИЙ ПРОВАЛ`.
   - ИИ строго развивает сюжет на основании того, преодолел ли герой СЛ.

3. **Реальный урон, смерть и Спасброски от смерти (D&D 5e Death Saves)**:
   - Реальное отнимание HP от атак врагов и ловушек.
   - При `0 HP` персонаж падает без сознания (`downed`), а консоль переключается на броски спасбросков от смерти (3 успеха = стабилизация, 3 провала = гибель, Нат 20 = оживление с 1 HP).

4. **Инвентарь и подбор трофеев (Loot Drops)**:
   - Сюжетная генерация предметов, найденных в ходе приключения (оружие, броня, зелья).
   - Подбор предметов в инвентарь одним кликом прямо с поля боя.
   - Применение целебных зелий (лечат и реанимируют при 0 HP) и смена активного оружия.

5. **Персональное древо прокачки и талантов**:
   - 3 ветки развития: Ветка Класса, Ветка Расы и Ветка Квенты (процедурно генерируется на основе текста биографии персонажа).
   - Получение опыта (XP) за раунды и очков талантов каждые 100 XP.

## 🚂 Развертывание на Railway (Railway.app)

Проект полностью оптимизирован для развертывания на **Railway** в один клик:

1. Зайдите на [Railway.app](https://railway.app) и нажмите **"New Project"**.
2. Выберите **"Deploy from GitHub repo"** и укажите репозиторий `themaximus/dndSivold`.
3. Railway автоматически определит `nixpacks.toml` / `railway.json`, установит зависимости, скомпилирует клиент и сервер, и запустит приложение.
4. В разделе **Variables** добавьте переменные:
   - `DEEPSEEK_API_KEY` — ваш ключ DeepSeek API (или `GEMINI_API_KEY`).
   - `JWT_SECRET` — секретный ключ сессий (любая надежная строка).
5. В разделе **Settings -> Networking** нажмите **"Generate Domain"** для получения публичного URL (например: `https://dndsivold-production.up.railway.app`).

Приложение готово для игры с друзьями через интернет!
